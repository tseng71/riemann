# 黎曼 ζ 函数简单临界线零点的七点稳定性改进

本公开仓库用于同行审阅一个由 AI 辅助形成的计算机辅助证明。论文把临界线上简单零点比例的下界提高到

\[
0.6730254768378743181\ldots .
\]

Claude 所用的 Montgomery--Taylor 基线为 `67.2500703679412%`；本稿的绝对提高约为 `0.0524773158463` 个百分点。

## 当前结论

这不是黎曼猜想的证明。当前准确状态是：**未经独立同行审阅的计算机辅助定理**。数学论文已经给出端到端推导；其条件是采用论文明确列出的 Arb/FLINT 信任基，并引用 Claude 的 Theorem D。它尚不能表述为“已获数学界确认”。

目前已经完成：

- 七点超越函数不等式在 Arb 区间算术下的穷尽验证；标准精度与更高精度重放均为 822,433 个节点、0 个未决叶节点；另有一条不导入主验证器的程序，以 2,048 份有理细分和精确有理 LDL 重查两个强凸盆地（超越函数区间仍使用 Arb/FLINT）；
- 新的有限维秩—迹稳定性、简单零点块的惯性分解、非对角 Gram 能量到谱缺陷的桥、连续七点窗口精确计数、任意有限主子块的谱压缩、抽象 267 平移汇总、条件式 267 点块桥、有限尾部拼接、保留谱缺陷的抽象 Theorem D 渐近源不等式，以及最终有理数装配的 Lean 证明；
- 已把真实的临界线上简单零点子类型按虚部严格递增编号为 `Fin (s₁(T))`，证明归一化相邻间距为正，并证明真实 Gram 矩阵的该重编号严格保持完整谱缺陷；
- 已为每个真实的连续 267 点窗口构造具体主 Gram 块与 266 个实际归一化间距，证明主块半正定、间距非负及跨度望远镜恒等式，并把条件式局部缺陷定理专门化到这些真实块；
- 已把全部真实连续块接入 267 个具体平移分割：每个满块都是主子块纤维，左右端点余块被显式纳入 `none` 纤维，并证明每个平移的满块谱缺陷和不超过全局谱缺陷；
- 已把全局相邻间距与各局部块逐项对齐，并在 Lean 中把局部块下界、267 平移汇总和精确有限简单零点计数合并成一个具体定理；
- 已在普通数学论证中证明中央端点删除只损失 `o(N)`，有限 Gram 元素一致逼近 Montgomery--Taylor 极限核的误差为 `O(1/log T)`，并证明全部 267 种平移上的总误差为 `o(N)`；
- 锁定版本、证书、测试、信任边界、来源说明和正式同行审阅稿。

仍未完成的是形式化与外部确认，而不是论文中缺失的数学推导：

- 把 Arb 的全部 822,433 节点重放为 Lean 证明项，或由不同区间库完整独立复核；
- 把论文中的端点、有限网格和一致核误差证明形式化为一个顶层 Lean 定理；
- 获得独立解析数论与计算机辅助证明专家的审阅、修正或确认。

因此，仓库把比例称为“论文中已证明、尚未经同行确认的计算机辅助定理”，不称为黎曼猜想证明，也不称为已经被共同体接受的纪录。
