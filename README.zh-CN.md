# 黎曼 ζ 函数简单临界线零点的七点稳定性改进

本公开仓库用于同行审阅一个由 AI 辅助形成的研究方案：尝试把临界线上简单零点比例的下界提高到

\[
0.6730254768378743181\ldots .
\]

## 当前结论

这不是黎曼猜想的证明，也还不是上述比例改进的端到端证明。

目前已经完成：

- 七点超越函数不等式在 Arb 区间算术下的穷尽验证；标准精度与更高精度重放均为 822,433 个节点、0 个未决叶节点；
- 新的有限维秩—迹稳定性、简单零点块的惯性分解、非对角 Gram 能量到谱缺陷的桥、连续七点窗口精确计数、任意有限主子块的谱压缩、抽象 267 平移汇总、条件式 267 点块桥、有限尾部拼接、保留谱缺陷的抽象 Theorem D 渐近源不等式，以及最终有理数装配的 Lean 证明；
- 锁定版本、证书、测试、信任边界、来源说明和论文草稿。

仍未完成：

- 把 Arb 的 822,433 节点证书重放为 Lean 证明项或由独立的小型验证器核验；
- 把已经 Lean 证明的窗口计数、主子块谱压缩和 267 余数类汇总具体接到按高度排序的中央简单零点 Gram 矩阵，构造余块并完成中央端点删除；
- 证明一致的有限 Gram—核误差估计；
- 将局部七点下界接入已经形式化的缺陷保持型 Theorem D 接口，并消去其剩余参数假设，得到无遗漏的顶层比例定理。

因此，`CLAIMS.md` 把七点不等式标为“外部严格证书”，把候选比例标为“端到端未闭合”。只有所有发布门槛通过后，仓库才会把候选比例改称已证明定理。
